## graphify

Project knowledge graph lives in `graphify-out/`.

- Codebase questions: `graphify query "<question>"` when `graphify-out/graph.json` exists.
- Relationships: `graphify path "<A>" "<B>"`. Concepts: `graphify explain "<concept>"`.
- After code edits: `graphify update .` (AST-only).
- Broad architecture: `graphify-out/GRAPH_REPORT.md` only if query/path/explain are not enough.
