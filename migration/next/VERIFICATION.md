- Формы используют общий серверный обработчик с валидацией, consent, honeypot, Origin, лимитом размера, нормализацией телефона, rate limit и экранированием HTML-письма. Форма/отправка/успех занимают одну область без перестройки соседнего контента.
- Canonical aokemz.ru, metadata, JSON-LD, sitemap, robots, cookie consent/Метрика; preview закрыт от индексации.

## Перед переключением production

1. Отдельный staging на целевом Timeweb: проверить Linux runtime, ресурсы build, SMTP, TLS, домен, reverse proxy и `TRUST_PROXY`. Не включать доверие произвольным forwarded headers. In-memory rate limit не является распределённым ограничителем нескольких экземпляров.
2. Backup/restore и baseline импортированной БД. **Не применять initial CREATE к уже заполненной БД.** Для пустой БД — явный versioned migrate; порядок в DEPLOY.md. Автоматический migrate при каждом старте не подключён намеренно.
3. PageSpeed Insights на доступном staging: результат 95+ для Next ещё не измерен и не обещан.
4. Dependency audit пока не чистый: установка оригинальных OJ-зависимостей сообщила 16 advisory (5 moderate, 11 high). Полный повторный security audit нового admin adapter остаётся release-gate; не делать force downgrade Payload ради зелёного отчёта.
5. В standalone stderr при быстрых переходах наблюдалось `The destination stream closed early`. В браузере проверенных страниц console/hydration errors не наблюдались. Нужна повторная проверка отмены SSR-запросов и нагрузки на Linux; ошибку не подавляли.
6. Delivery API экспорт включает весь опубликованный контент, но не Contentful-черновики. Для них потребуется Management API, если такие записи нужно сохранить.

Это подтверждение локального переноса публичного сайта, не разрешение на переключение production и не утверждение о завершённом release audit.
