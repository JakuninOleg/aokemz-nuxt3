# Layout & component patterns

## Shell

- Desktop: sticky top header (logo, nav, phone, CTA) replaces or demotes legacy left sidebar over time.
- Mobile: burger + full-width content; large tap targets on CTA.

## Grid

- Marketing sections: full-bleed media OK; text in ~max-w-6xl centered or split 50/50.
- Catalog: responsive card/grid is OK (interaction container); keep borders quiet.

## Form block

- Dark section background; inputs on `--kemz-paper` with clear labels (not placeholder-only).
- Primary button: solid `--kemz-blue`; secondary: outline on dark.

## Product hotspot

- Pin + thin connector line + short label.
- Keyboard focusable pins; captions readable without hover-only on mobile (stack list under image).

## Email HTML

- Table-based simple layout, inline CSS, logo/text header «Заявка с aokemz.ru», labeled rows, footer with timestamp.
- Compatible with common clients; no external fonts required.
