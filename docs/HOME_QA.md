# Главная КЭМЗ: реализация нового референса

Ветка: `dev-codex`. Область редизайна: главная `/`, её вариант шапки/подвала и технической формы. Изменения типов в других routes исправляют проверку TypeScript, а не меняют их дизайн.

## Компоненты и данные

- `components/home/HomePage.vue`: композиция страницы.
- `HomeHero`, `HomeShowcase`, `HomeProduction`, `HomeCapabilities`, `HomeGeography`, `HomeRequest`, `HomeNews`: отдельные секции в порядке референса.
- `HomeEngineeringIcon`: небольшие SVG-иконки для показателей и этапов.
- `assets/css/home.scss`: токены и адаптивная вёрстка, ограниченные главной.
- `components/AppHeader.vue`, `components/AppFooter.vue`: компактный вариант только на главной.
- `components/Form.vue`: необязательный вариант `technical`, существующая валидация, маска телефона, согласие и `/api/sendMail`. Параметры оборудования сериализуются в существующее поле `message`.
- Категории и последние три новости: текущий Contentful; мощности, возможности и география: данные проекта и `docs/brand-facts.md`.

## Ассеты

Использованы оптимизированные копии предоставленных изображений: `hero-quarry-dragline`, `drilling-rig-quarry`, `underground-mine-rail`, `mine-locomotive`, `high-voltage-switchgear`, `motor-rotor-workshop`, `drive-gearboxes`, `machined-steel-shaft`, `electric-machinery-shop`, `machined-metal-components`. Оригинальные PNG сохранены. Скрипт повторной оптимизации: `scripts/prepare-home-assets.cjs`.

Существующая карта `map-eurasia-supply.webp`, существующий логотип и реальные фото новостей из CMS. Заголовки: локальный Roboto Condensed с кириллицей и OFL-лицензией в `public/fonts`; основной текст: ProximaNova из проекта.

## Отличия от изображения

- Показатели и новости соответствуют реальному контенту, поэтому не повторяют вымышленные примеры screenshot.
- Сохраняется реальный логотип предприятия. Клиентские логотипы из макета не выдумываются; вместо них названия площадок из данных сайта.
- Поиск, английская локаль, видеоролик, слайдер и Telegram отсутствуют в текущей функциональности; фиктивные контролы не добавлены.
- Backend не принимает вложения. Вместо кнопки загрузки файла используется поле «Задача»; технические параметры передаются через существующий контракт.
- Промышленные изображения являются предоставленными иллюстрациями, а не фотографиями конкретных изделий или цехов КЭМЗ.

## Проверки

- `npm run lint`: успешно после добавления Vue/TypeScript-конфигурации.
- `npx nuxi typecheck`: успешно после закрепления совместимых версий инструментов и исправления старых аннотаций Contentful, head API и Zod.
- Production build: успешно, включая Nitro (вне sandbox; внутри него файловый tracing ограничен правами). Осталось предупреждение Node DEP0155 в зависимостях Nuxt/Vue, Sass deprecation warnings отсутствуют.
- Chromium: выполнены снимки 1440×900, 1024×768, 768×1024, 430×932, 390×844, 360×800. На всех размерах `scrollWidth === innerWidth`, битых изображений нет. Проверены композиция, типографика, сетка, отступы, кадрирование; после первого прохода скорректированы crop hero и интенсивность фона формы.
- Файлы снимков: `artifacts/home/`, в том числе `1440-full.png`, `1024-first.png`, `390-first.png` и desktop-секции.
- SEO title/canonical и реальные URL категорий проверены браузерным тестом. Пройдены: открытие/закрытие карты, мобильное меню, Escape, переход к форме, блокировка пустой формы, нормализация телефона, сериализация технических параметров, состояние успешной отправки с подменённым транспортом. Сервер отклоняет пустой запрос HTTP 400. Реальное письмо не отправлялось.
- Последний визуальный прогон: ошибок консоли нет. Последний тест взаимодействий: ошибок JavaScript нет. Исправлен race при закрытии Leaflet; CMS-запросы ограничены 8 секундами без повторов, чтобы сбои Contentful не блокировали SSR длинными цепочками retry.

Скрипты QA используют установленный Chromium и Playwright из runtime. Перед запуском задать `KEMZ_NODE_MODULES` (папка node_modules с playwright) и `KEMZ_CHROMIUM` (путь к chrome.exe), затем `node scripts/check-home.cjs` и `node scripts/check-home-behavior.cjs`. Последний перехватывает отправку валидной заявки: реальное письмо не отправляется.

Для production-проверки параллельно dev: `$env:KEMZ_BUILD_DIR='.nuxt-validation'; npm run build`. Отдельный buildDir защищает работающий dev-сервер от перезаписи `.nuxt`.
