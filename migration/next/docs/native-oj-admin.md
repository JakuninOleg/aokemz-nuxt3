# Native Payload с оформлением OJ CMS для КЭМЗ

Админка находится только на `/admin`. Её страницы создаются штатными `RootPage`
и `RootLayout` из `@payloadcms/next`. Авторизация, редакторы коллекций, версии,
поиск, фильтры, загрузка медиа и права доступа принадлежат Payload.

## Оформление

- `src/components/cms/oj-admin.scss` — тема OJ, адаптированная под КЭМЗ.
- `OJBrand` — эмблема и название КЭМЗ.
- `OJNav` / `OJNavClient` — штатное расширение навигации Payload с учётом прав.
- `OJDashboard` — штатное серверное представление обзора; данные запрашиваются
  через Payload Local API с контекстом текущего пользователя и проверкой доступа.
- Ссылка разработчика ведёт на `https://jakuninoleg.dev/ru`.
- Новости редактируются штатным Lexical с постоянной панелью инструментов.

Отдельная оболочка `(oj-cms)`, её API и копия интерфейса `src/oj` выведены из
приложения. Восстанавливаемая копия находится вне Git в
`.migration-private/retired-admin-2026-10-08`. База и S3 не изменялись.

Старый `/payload-admin` и короткие адреса коллекций перенаправляются на native
маршруты `/admin/collections/...` с HTTP 308. Старый `/api/oj-cms` больше не существует.
